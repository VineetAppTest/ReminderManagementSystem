# RemindIQ 3N.11 Acceptance Checklist

## Persistence

- [ ] Reminder is saved before alarm scheduling.
- [ ] Reminder appears under Reminder tab immediately after confirmation.
- [ ] Refresh app: reminder still appears.
- [ ] Close/reopen app: reminder still appears.

## Alarm UI

- [ ] No white blank WebView panel.
- [ ] No floating-only "ALARM RINGING" pill.
- [ ] Full-screen alarm surface appears.
- [ ] Reminder title is visible.
- [ ] Alarm time is visible.
- [ ] Snooze 5m is visible.
- [ ] Dismiss is visible.
- [ ] Open RemindIQ is visible.

## Behavior

- [ ] Snooze updates dueAt by about 5 minutes.
- [ ] Dismiss marks reminder dismissed/notified.
- [ ] Dismissed reminder does not remain under Upcoming.
- [ ] Future reminder is not placed under Reminded.

## Build

- [ ] Build label shows `Sprint 3N.11 · P0 Alarm Recovery`.
- [ ] App version shows `3N.11-P0`.
