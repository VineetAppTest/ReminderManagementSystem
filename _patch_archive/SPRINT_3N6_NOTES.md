# Sprint 3N.6 Notes

## Trigger
3N.5 fixed full-screen triggering and Done action, but the Reminder cards clipped content/buttons and the alarm control UI required better visual quality.

## Acceptance criteria
1. Done alarm cards show status/category, title, alarm time, event/repeat information, Details where applicable, and Restore/Edit/Delete action row without clipping.
2. Cards scroll normally within the Reminder panel.
3. Full-screen alarm has compact premium visual treatment.
4. Snooze and Done remain on the same screen.
5. Done stops alarm and exits cleanly.
